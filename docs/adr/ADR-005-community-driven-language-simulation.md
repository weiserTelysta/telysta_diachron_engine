# ADR-005：以言语社区和使用为核心的语言模拟架构

- 状态：`Proposed (staged; not a WS-1 prerequisite)`
- 日期：2026-07-12
- 决策范围：祖语生成、历时变化、分支、词汇扩充和语言质量模型

## 背景

当前引擎以概念表独立生成词形，再对每个词概率应用音变，并在固定 Epoch 注入领域词和复合词。这一架构可以展示历时效果，但不能充分解释创新如何产生和传播，也无法根据交际需求判断语言规模。

已观察到的问题包括：

- 创世形式可能违反自身音系约束；
- 同 seed 不能复现；
- 同源词缺乏稳定对应保证；
- 环境、审美、社会结构和谱系继承混在同一偏置层；
- 词汇扩充由固定文件驱动；
- 类型学状态可能随机变化，而不是由具体语法化和重分析推导；
- 分支模拟没有复用完整主演化过程。

## 拟议决策

采用多尺度、使用驱动的混合模拟：

1. `LanguageBlueprint` 描述用户锁定项、经验先验、审美偏好和可涌现特征；
2. `SpeechCommunity` 描述人口、网络、接触、威望、识字和标准化；
3. `ProtoLanguageCompiler` 编译内部一致的祖语，而不是逐词独立随机；
4. `CommunicationNeeds` 和使用语料产生词汇、语义和构式需求；
5. `ChangeProcess` 将变化拆为创新、采用、社会扩散、词汇扩散、重组和类推；
6. `LanguageFamilyGraph` 管理继承、迁徙、隔离和接触；
7. `ProvenanceLedger` 记录每个形式、义项、词素和构式的历史来源；
8. 所有状态通过 `StateTransaction` 修改，并由版本化 Operation/Run locks 所约束的 `RngTree` 提供随机流；执行层 Job/Attempt 不得改变随机身份。

第一版 `SpeechCommunity` 使用群体级参数，不模拟每个个体说话人。只有当群体模型无法满足已定义的研究问题，并有性能预算时，才引入 agent-based 模拟。

本 ADR 是跨多个产品阶段的研究架构提案，不是 WS-1 的实现前置，也不授权任何新的持久化 schema。WS-1 的 LanguageState、ChangeSet 和 Genesis 边界由 ADR-007 至 ADR-010 决定；Project、Operation、Run 与 Job 身份由 ADR-011 决定。SpeechCommunity、PopulationVariationState、ChangeProcess 和家族模型仍需在各自实现 Gate 前通过独立 ADR 决定。后续 ADR 可以接受、替代或否决本提案中的局部机制，而不需要等待本 ADR 的全部长期证据。

## 知识分层

系统明确区分：

- 普遍或项目内部硬约束；
- 跨语言统计先验；
- 仍有争议的研究假说；
- 用户审美和世界观选择。

环境标签不得直接决定语言类型。自然环境优先影响交际需求、迁徙、隔离和接触；对音系的争议性影响必须是可关闭的低置信度假说。

## 被否决的方案

### 继续扩充现有逐词规则链

否决原因：规则数量增加不会解决状态不一致、扩散缺失、历史对应和固定扩词问题。

### 完全交给 LLM 生成语言

否决原因：不可复现、难以约束、无法保证范式和历史一致，也难以提供专业审计。

### 立即模拟每个说话人

否决原因：状态空间、参数识别和性能成本过高；当前缺少能证明个体级模型必要的产品任务。

### 将现有 Python 实现逐行翻译为 Rust

否决原因：当前模型本身存在状态、回放、随机流和语言生成缺陷。机械翻译会固化这些问题。生产核心采用 Rust 的决策见 [ADR-006](./ADR-006-rust-native-core-python-research-bridge.md)，但迁移必须以新的领域模型和质量门为准；Python 仅保留为研究桥接和对照基线。

## 后果

正面影响：

- 语言结构、历史和产品交互具有统一心智模型；
- 偏好、环境和社会因素不再混为未经证实的因果规则；
- 分支和接触能够产生可审计的历史层次；
- 词汇规模由使用需求判断；
- 可为专业评审提供完整来源和不确定性。

成本与风险：

- 需要重构核心状态和事件模型；
- 需要建立经验数据治理和版本管理；
- 需要新的语料、构式和质量基准；
- 模拟参数增多，必须通过 Quick/Expert/Research 三种模式管理复杂度；
- 旧项目格式需要迁移。

## 阶段性证据义务

以下项目是分阶段验证义务，不是 WS-1 开工前必须同时满足的接受条件：

| Gate | 必须取得的证据 |
|---|---|
| G2 / WS-1 | 一个小型 LanguageBlueprint 能编译硬约束错误为零的祖语；同版本、同锁和同 seed 的结果可复现并可由 GenesisArtifact 与 typed ChangeSet 回放 |
| G3 | CommunicationNeeds 或等价的任务驱动扩充机制能识别表达缺口，并在受支持范围内提出至少三类可审计策略；策略是提案而不是未经验证的语言规律 |
| G4 / WS-2 | SpeechCommunity 参数通过 observation、adoption 或 propagation 过程改变扩散结果，不能直接覆盖语言结构；成功、失败、残留和逆转均可表示 |
| G5 / Family | 一个 ChangeProcess 能在两个分支中产生稳定但不同的规律对应，并能区分继承、接触和偶然相似 |

本 ADR 只有在上述分阶段决定已有 Accepted ADR、相应证据完成且未留下相互矛盾的身份或回放语义后，才可以整体转为 `Accepted`；更可能的关闭方式是由若干范围更小的 Accepted ADR 明确替代。当前状态保持 `Proposed`。
